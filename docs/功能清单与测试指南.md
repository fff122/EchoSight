# 回声视见（EchoSight）功能清单与测试指南

> 适用版本：2026-09-25 之后的 CI 构建（包含方案A记忆系统与快速识图节奏）
> 给测试人员：照着下面的用例逐条测，把**你说的原话、App 的播报原话、当时的场景**记下来反馈。

## 一、安装与准备

1. 从 GitHub Actions 最新构建下载 `EchoSight-apk` 安装（或直接拿 release APK 侧载）。
2. 需要网络（云端语音识别/合成 + AI 识图都走云端）。
3. 建议环境：室内、手机音量开大、环境噪音不要过大（太吵会听不清你说话）。
4. 交互方式只有一个：**按住屏幕下方的大按钮说话，说完松手**。每一轮指令都要按一次。

## 二、功能清单（14 项）

| # | 功能 | 说法入口 |
|---|------|---------|
| 1 | 找常见物品（YOLO 实时） | "找杯子 / 找椅子 / 找电视…"（80 类） |
| 2 | 找任意物品（AI 兜底） | "找耳机 / 找药盒…"（不在 80 类的都行） |
| 3 | 按参考照片找个人物品 | 同上；登记过的物品自动按照片比对 |
| 4 | 记忆先行播报 | 说"找XX"时自动先报"记忆里它在客厅的茶几上" |
| 5 | 扫描房间登记（方案A） | "扫描" → 报房间名 → 转一圈 → "扫完了" |
| 6 | 记忆查询 | "耳机在哪" |
| 7 | 手动登记 | "记一下，遥控器在茶几上" |
| 8 | 删除记忆 | "忘掉耳机" |
| 9 | 申报所在房间 | "我在客厅" |
| 10 | 找到待命 | "找到了" |
| 11 | 语音帮助 + 教程 | "帮助" → 按提示回答 |
| 12 | 方位/距离播报 | 找到时自动：左前方/正前方、约几步、高低位置 |
| 13 | 靠近/远离提示 | 持续看到目标时自动说"你在靠近/继续走" |
| 14 | 无障碍界面 | 大字、状态色、TalkBack、录音按钮变红 |

## 三、分功能测试用例

### 1. 找常见物品（核心路径）
- 在桌上放一个**杯子**，说"找杯子"。
- 预期：几秒内播报"看到杯子，在画面左前方，大约 2 步…"之类；走动时会更新"你在靠近"。
- 变化测试：把杯子挪远/拿走，确认播报跟着变；画面里有 2 个同类物品看会不会来回跳。

### 2. 找任意物品（AI 兜底）
- 拿一个**耳机**（不在 80 类），放在桌面，说"找耳机"。
- 预期：约 1 秒后开始第一次 AI 查看；**你走动时每约 5 秒看一次**，停下来变慢（12 秒）。
- 关键体验点（上一版慢的修复）：AI 报"有，在画面中间"后继续往前走，下次查看说"没有"时，应提醒"**刚才还在画面里，请放慢脚步，往回转**"。
- 反馈重点：从说到"找耳机"到第一次听到结果用了几秒？有没有走过头？

### 3. 扫描房间登记（重点新功能）
- 说"扫描" → 应问"这是哪个房间？" → 答"客厅"。
- 拿手机慢慢转一圈 → 过程中应逐批口播"看到电视、茶几…"（每约 8 秒一批，画面不动不播）。
- 说"扫完了" → 等 10-70 秒（打框较慢）→ 播报"客厅登记了 N 样东西：…"。
- 验证：用手机文件管理器看 `Android/data/com.echosight.app/files/memory/`：
  - `memory.json` 里有登记条目
  - `snapshots/` 有带绿框的快照图（给陪行的人看的）
  - `refs/` 有每个物品的小图（参考照片）
- 再测：扫第二个房间（卧室），确认房间标签不混。

### 4. 记忆查询 / 手动登记 / 删除
- 登记过遥控器后说"遥控器在哪" → 应报"记忆里，遥控器在客厅…，X 分钟前记录的"。
- 说"记一下，药盒在床头柜上" → 应答"记下了：药盒在床头柜上"；再用第 6 条验证。
- 说"忘掉药盒" → "已经忘掉"；再查询应说"记忆里还没有"。

### 5. 记忆先行 + 照片比对
- 对已扫描登记的物品说"找XX" → 开头应先播"记忆里它在客厅…"。
- 把登记过的物品换个背景放置 → "找XX" → AI 应按参考照片认出（比第一次没照片时更准）。

### 6. 找到/待命
- 目标在画面里时说"找到了" → "好的，我先安静待命"，之后不再播报。
- 再说"找XX"能正常唤醒新搜索。

### 7. 帮助与教程
- 说"帮助" → 应列出 6 个功能并问"需要播报使用教程吗？"
- 说"是" → 问"你要学哪个功能？" → 说"扫描房间" → 播报对应教程。
- 说"全部" → 从第一个开始挨个讲。说"不用/退出"能随时出来。
- 帮助中途直接说"找杯子" → 应退出帮助并开始找杯子。

### 8. 稳定性
- 断网状态说"找杯子"：应播报明确的失败提示，不应闪退。
- 快速连按按钮、乱说一句话（"今天天气不错"）：不应闪退，应有"没听懂"回应。
- 扫描中途说"取消扫描"：应干净退出，不影响之后正常找东西。

## 四、已知边界（不是 bug，但要知道）

- 打框快照的框不一定贴合（AI 输出坐标有误差），只用于人工核对，不影响语音功能。
- ASR 偶尔听错房间名/物品名，需要再说一遍；太嘈杂环境更容易发生。
- AI 识图是"看一眼"不是连续跟踪：请走慢一点，看到报位置后原地确认。
- 找 COCO 外物品依赖网络与 AI 响应，弱网时会明显变慢。
